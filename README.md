# Blackbox

> 영상 기반 이상행동 감지 및 사람 추적 시스템  
> CCTV 또는 카메라 영상에서 사람을 탐지·추적하고, 카메라 가림, 도어락 접근, 장시간 머무름 등 이상 상황을 감지하는 Python 기반 AI 영상 분석 프로젝트입니다.

<br/>

## 1. 프로젝트 소개

Blackbox는 카메라 영상에서 사람과 특정 행동을 분석하여 이상 상황을 감지하는 AI 영상 처리 프로젝트입니다.

영상 속 사람을 탐지하고 ID를 부여하여 추적하며, 유사한 복장을 가진 사람이 등장해도 동일인 여부를 더 안정적으로 판단할 수 있도록 ReID 기반 추적 방식을 적용했습니다. 또한 카메라 가림, 문고리/도어락 접근, 특정 구역 체류 등 보안 관점의 이벤트를 감지하고 화면에 시각적으로 표시할 수 있도록 구현했습니다.

<br/>

## 2. 주요 기능

- 영상 기반 사람 탐지
- 사람별 ID 부여 및 추적
- ReID 기반 동일인 재식별
- 장시간 머무름 감지
- 도어락/문고리 접근 행동 감지
- 카메라 가림 감지
- 카메라 반전 및 로컬 설정 관리
- 이상 상황 발생 시 경고 UI 표시
- 테스트 영상 기반 감지 결과 검증

<br/>

## 3. 기술 스택

| 영역 | 기술 |
|---|---|

| Video Processing | OpenCV 기반 영상 처리 |

| UI | 영상 위 Bounding Box, Warning UI |

<br/>

## 4. 프로젝트 구조

```text
Blackbox
├── behaviors      # 이상행동 및 이벤트 판단 로직
├── core           # 실행 흐름 및 핵심 처리 로직
├── detection      # 객체/사람 탐지 관련 로직
├── models         # AI 모델 관련 파일
├── scripts        # 실행 및 보조 스크립트
├── settings       # 로컬 설정 및 환경 설정
├── test_data      # 테스트 영상 및 데이터
├── tracking       # 사람 추적 및 ReID 기반 추적 로직
├── utils          # 공통 유틸 함수
├── main.py        # 메인 실행 파일
└── test.py        # 테스트 실행 파일
````

## 5. 팀원 역할

| 이름 | 담당 영역                                        | 주요 기여                                                                                                                                                                                |

| 한윤지              | Tracking / ReID / Camera Blocking            | 사람 추적 알고리즘과 장시간 머무름 감지 로직을 구현했습니다. 기존 방식이 유사한 복장의 다른 사람에게 취약한 문제를 개선하기 위해 ReID 모델을 추가하고, 사람 crop에서 추출한 임베딩을 기준으로 동일인 판단 안정성을 높였습니다. 또한 얼굴 탐지 기반 카메라 가림 감지와 카메라 블로킹 UI 개선 작업을 담당했습니다. |
| 강성재                   | Test / Tracking Parameter / Demo Video       | 테스트 영상과 `test.py`를 수정하며 실제 영상 기반 검증을 담당했습니다. 사람 ID 표시 방식, tracker 파라미터 조정, Bounding Box 색상 수정, GPU 사용 설정과 모델 크기 변경 등을 통해 시연 환경과 테스트 안정성을 개선했습니다.                                     |

| 홍원희               | Camera Blocking Detection                    | 기존 밝기 기반 카메라 가림 감지 방식의 한계를 개선했습니다. 텍스처 손실, 경계 밀도, 히스토그램 이동, 채도, 옵티컬 플로우 연산을 추가하여 카메라 가림 감지 정확도를 높이는 작업을 담당했습니다.                                                                      |

## 7. 프로젝트를 통해 배운 점

Blackbox 프로젝트를 통해 영상 AI 서비스는 단순히 객체를 탐지하는 것에서 끝나지 않고, 탐지 결과를 시간 흐름에 따라 추적하고 행동으로 해석하는 과정이 중요하다는 것을 배웠습니다.

특히 유사한 복장을 가진 사람이 등장했을 때 기존 추적 방식만으로는 동일인 판단이 어렵다는 문제를 경험했고, ReID 기반 임베딩을 활용해 추적 안정성을 높이는 방향으로 개선했습니다.

또한 카메라 가림 감지는 밝기 변화만으로 판단하기 어렵기 때문에 텍스처, 경계, 히스토그램, 채도, 옵티컬 플로우 등 여러 시각적 특징을 함께 고려해야 한다는 점을 배웠습니다.
